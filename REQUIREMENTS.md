# Requirements

- Python 3.10 or newer recommended.
- No third-party Python packages are required.
- macOS/Linux/POSIX shell for bundled `.sh` wrappers.
- Local HVSC tree only needed for Top-100 batch conversion.

Bundled C64 ROM files must remain beside `sid2midi.py` under `roms/` for RSID/KERNAL-sensitive conversions:

```text
roms/basic.bin
roms/chargen.bin
roms/kernal.bin
```
