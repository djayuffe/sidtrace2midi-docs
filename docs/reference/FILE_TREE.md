## Root files

Root files are meant for normal users and release validation. Detailed learning material lives in `docs/`.

## Docs layout

- `docs/modules/` explains each code module.
- `docs/steps/` explains each pipeline step.
- `docs/deepdives/` explains complex internals.
- `docs/tutorials/` gives task-oriented workflows.
- `docs/operations/` covers QA, release and troubleshooting.
- `docs/reference/` is lookup material.
- `docs/branding/` covers project naming and logo usage.
